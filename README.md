# Trivio Rescue Business Website

This repository contains a simple static business website scaffold designed for GitHub Pages.

## Included files

- `index.html` — homepage and main business landing page
- `assets/css/styles.css` — responsive styling
- `assets/js/script.js` — mobile menu behavior and form UI feedback
- `.nojekyll` — optional file to ensure GitHub Pages serves static assets correctly

## Deploying to GitHub Pages

1. Push this repository to GitHub.
2. In the repository Settings, open **Pages**.
3. Set the source to the `main` branch (or `master`) and the root folder.
4. Save and wait for the site to publish.

Your site will be available at `https://<username>.github.io/<repository>`.
